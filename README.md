# Proyecto de gráfica: escenario deportivo OpenGL

Repositorio con la documentación solicitada, una copia del código C++ principal y un ZIP con el proyecto completo para compilar.

## Archivos

- `DOCUMENTACION_TECNICA.md`: memoria técnica y matriz de requisitos.
- `ACTA.md`: acta para completar con los datos y firmas reales.
- `main.cpp`: copia individual del código C++ principal.
- `proyectoGrafica_OpenGL.zip`: proyecto completo, con CMake, dependencias, shaders, GLB y el código fuente organizado en carpetas.

## Clonar

```powershell
git clone https://github.com/Ur182/proyectoGrafica_OpenGL.git
```

Después de clonar, extrae `proyectoGrafica_OpenGL.zip`. Abre la carpeta extraída en Visual Studio 2022 con **File > Open > Folder** y sigue el README que viene dentro del ZIP para instalar dependencias, compilar en x64 y ejecutar.

La compilación y la ejecución aún deben comprobarse en Windows con Visual Studio 2022 y vcpkg.
